# easy-hyprland-dot-files
## 📦 What gets installed

### 🖥️ Status Bar
| App | Description |
|-----|-------------|
| [Waybar](https://github.com/Alexays/Waybar) | Highly customizable status bar with CSS, shows workspaces, time, network, volume, etc |

### 🚀 Launcher
| App | Description |
|-----|-------------|
| [Rofi](https://github.com/lbonn/rofi) | Application launcher and general menu, fully customizable with CSS |

### 🔔 Notifications
| App | Description |
|-----|-------------|
| [Swaync](https://github.com/ErikReider/SwayNotificationCenter) | Notification daemon with built-in side panel, styleable with CSS |

### 🖼️ Wallpaper
| App | Description |
|-----|-------------|
| [Swww](https://github.com/LGFae/swww) | Wallpaper daemon with animated transitions between images |

### 🛠️ Utilities
| App | Description |
|-----|-------------|
| [Wl-clipboard](https://github.com/bugaevc/wl-clipboard) | Clipboard manager for Wayland |
| [Brightnessctl](https://github.com/Hummer12007/brightnessctl) | Screen brightness control from keybinds |
| [Playerctl](https://github.com/altdesktop/playerctl) | Media playback control for bar keybinds |


and hyprland config gui
